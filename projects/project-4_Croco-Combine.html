📖 Как играть — полный гайд

🎯 Базовый принцип

Один игрок видит слово на экране и объясняет его команде выбранным способом. Команда угадывает. Угадали — жмите «Дальше» для следующего слова.

🧒 Уровни сложности

  • Детский — только простые и весёлые слова, без сложного и 18+.
  • Лёгкий — для разминки, конкретные предметы и действия.
  • Средний — бытовые ситуации, профессии, абстракции.
  • Сложный — абстракции и фразы для опытных.
  • 18+ — взрослые темы. Используйте с осторожностью.
  • Бесконечность — смешивает все локальные базы и внешние источники.
  • Рандом — случайный выбор из всех уровней.

💬 Режимы объяснения

  • 🤐 Без слов — только жесты и мимика. Нельзя говорить, шептать, беззвучно артикулировать, показывать буквы, рисовать, указывать на предметы не при вас.
  • 💬 Другими словами — синонимы, антонимы, ассоциации. Нельзя называть само слово и однокоренные.
  • ✏️ Нарисовать — рисуй на бумаге или в воздухе. Без букв и цифр.
  • 😮 Открытый рот — говори, широко открывая рот. Артикуляция — твой инструмент.
  • 😐 Закрытый рот — говори, не разжимая губ. Слово должно быть понято сквозь «кашу».
  • 1️⃣ Одно слово — только одно слово-ассоциация. Больше ничего.
  • 🔔 Звуками — только звукоподражания: мычи, пищи, стучи.
  • 🚫 Taboo — нельзя называть запрещённые слова (показываются рядом со словом).
  • 📞 Глухой телефон — слово видит только первый. Шепчет второму быстро и один раз. Второй — третьему. Последний говорит вслух. Потом каждый говорит, что услышал.
  • 🔄 Обратный — объясняющий отвечает только «да» или «нет». Угадывающие задают вопросы.
  • ✂️ Пополам — слово делим на две части. Первую половину показывает первый игрок, вторую — любой выбранный (или следующий по кругу). Можно делить по смыслу: один — жестами, второй — словами.

🎭 Эмоция (опционально)

Если выбрана эмоция, объясняйте слово в этой манере: радостно, злобно, испуганно, влюблённо. Это не отдельный режим, а модификатор. Отлично сочетается с «Другими словами», «Открытым/Закрытым ртом».

⚡ ГИПЕР КОМБО

Кнопка случайно выбирает сложность, режим и эмоцию, затем показывает слово. Каждый раз — новое сочетание. Идеально для разогрева или когда не можете определиться.

📞 Глухой телефон — как играть

  1. Слово видит только первый игрок.
  2. Он шепчет слово на ухо второму быстро и один раз. Повторять нельзя.
  3. Второй передаёт третьему то, что услышал. И так до конца цепочки.
  4. Последний громко называет то, что до него дошло.
  5. После этого каждый по цепочке говорит, что он услышал. Сравниваете с исходным словом.

🚫 Taboo — как играть

Рядом со словом показываются 3 запрещённых слова. Их нельзя произносить (и однокоренные тоже). Объясняйте остальными словами.

🔄 Обратный Alias — как играть

Объясняющий не говорит ничего, кроме «да» или «нет». Угадывающие задают вопросы: «Это живое?», «Это можно съесть?». Задача — угадать слово за минимум вопросов.

📚 Источники слов

Слова собраны из открытых списков для «Крокодила» и «Алиаса», а также из онлайн-генераторов igra-crocodil.ru и croco-game.ru. Правила режимов основаны на классических правилах Alias и «Испорченного телефона».
